## 摘要
我们介绍了对PIGEON（噬菌体与整合基因组，是否包被）参考数据库的更新，该数据库包含全球生态系统中DNA病毒序列（vOTU，主要为dsDNA噬菌体）。为反映仅包含来自病毒大小分级宏基因组（病毒组）的vOTU，我们将数据库重新命名为PEONY（仅包被噬菌体），并提供了总结该数据库实用性的新数据。

## Abstract
We present an update to the PIGEON (Phages and Integrated Genomes Encapsidated or Not) reference database of DNA viral sequences (vOTUs, mostly dsDNA bacteriophages) from global ecosystems. To reflect the inclusion of only virus size-fractionated metagenome- (virome-)derived vOTUs, we reintroduce the database as PEONY (Phages Encapsidated ONlY) and present new data summarizing the utility of the database.
