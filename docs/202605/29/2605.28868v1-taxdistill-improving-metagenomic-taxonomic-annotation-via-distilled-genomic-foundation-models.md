## 摘要
宏基因组分类注释旨在识别环境样本中DNA片段的微生物来源。传统方法依赖于序列相似性，但常常受到高微生物多样性和参考数据库不完整性的限制，这促使了诸如Taxometer等学习方法的开发，这些方法通过事后校正来学习更具信息量的宏基因组序列表示。然而，这些方法通常依赖于训练期间从相似性搜索工具获得的标签，这不可避免地引入了噪声，从而损害表示学习并降低分类性能。为了解决这个问题，我们提出了TaxDistill，一种用于宏基因组分类的知识蒸馏框架。我们引入了GenomeOcean，一个拥有5亿参数的基因组基础模型，作为教师网络来提取深层语义特征并根据置信度生成软标签。通过将这些软标签信息蒸馏到一个轻量级的学生网络中，TaxDistill有效减少了初始检索工具引入的标签噪声。在七个不同的CAMI2数据集上的综合实验表明，TaxDistill在大多数场景下优于现有基线。例如，在胃肠数据集上，它将MMseqs2的F1分数从0.763提高到0.941，优于Taxometer基线。总体而言，TaxDistill为复杂宏基因组分析中的标签校正提供了一种可靠的方法。

## Abstract
Metagenomic taxonomic annotation aims to identify the microbial origins of DNA fragments in environmental samples. Traditional methods that rely on sequence similarity are often constrained by the high microbial diversity and the incompleteness of reference databases, which has motivated the development of learning approaches such as Taxometer that perform post hoc correction to learn more informative metagenomic sequence representations. However, these methods typically rely on labels derived from similarity search tools during training, which inevitably introduces noise that can impair representation learning and degrade classification performance. To address this issue, we propose TaxDistill, a knowledge distillation framework for metagenomic classification. We introduce GenomeOcean, a 500M parameter genomic foundation model, as the teacher network to extract deep semantic features and generate soft labels based on confidence. By distilling this soft label information into a lightweight student network, TaxDistill effectively reduces the label noise introduced by initial retrieval tools. Comprehensive experiments on seven diverse CAMI2 datasets demonstrate that TaxDistill outperforms existing baselines in most scenarios. For instance, on the Gastrointestinal dataset, it improves the F1 score of MMseqs2 from 0.763 to 0.941, outperforming the Taxometer baseline. Overall, TaxDistill provides a reliable method for label correction in complex metagenomic analysis.

### 方法论文提出的方法论

- **核心思想**：提出 TaxDistill 框架，采用教师-学生架构。教师网络为预训练的大规模基因组基础模型 GenomeOcean（500M 参数），负责提取深层语义特征并基于置信度输出软标签概率分布；学生网络保持轻量 MLP 结构（类似 Taxometer），处理手工设计的特征（四核苷酸频率、跨样本丰度等）。通过最小化学生预测与教师软标签之间的 KL 散度（知识蒸馏损失），并结合学生自身的层次分类损失，共同优化学生网络，从而减少噪声标签的负面影响。
- **关键技术细节**：
  1. **教师网络**：使用冻结的 GenomeOcean 骨干 + 可学习分类头，独立通过深度层次损失（Deep Hierarchical Loss）优化，用于输出概率分布。
  2. **学生网络**：输入为 (103+K+1) 维特征，包含 TNFs、K 个环境丰度及总丰度，通过 MLP 输出分类概率。
  3. **蒸馏过程**：引入温度参数 τ>1 软化分布，定义 `L_KD = τ²/N * Σ_i Σ_l qT(l|sg(zT_i); τ) * log( qT / qS )`。教师停止梯度更新，只由层次损失更新；学生由加权组合 `α L_hier + (1-α) L_KD` 更新，总损失为教师损失与学生损失之和。
  4. **分类路径**：在预测时，严格阈值 0.80 进行叶节点概率截断，路径仅扩展到概率超过 0.5 的子节点，以控制假阳性。

### 论文的主要结论与发现

1. **TaxDistill 在绝大多数场景下优于 Taxometer 和初始检索工具**：15 个人类微生物组测试中，13 例 F1 优于 Taxometer；Marine 和 Rhizosphere 数据集上也一致领先。
2. **软标签蒸馏能有效赋予学生网络不确定性感知**：在高风险预测时，TaxDistill 能谨慎地将样本重新分配为“未标记”类别，严格抑制假阳性，在临床应用中尤为重要。
3. **GenomeOcean 的深层语义特征比浅层手工特征（TNFs）更有效**：TaxDistill 始终优于 Taxometer_G，说明单纯替换为基因组基础模型嵌入而不进行蒸馏不足以显著提升校正性能。
4. **教师模型规模增大带来边际提升**：500M 参数教师模型总体上略优于 100M 模型，但差距不大。
5. **对于激进分类器（如 Kraken2）效果尤为明显**：TaxDistill 能够有效将大量错误预测转为未标记，大幅提升 Precision，例如在 Rhizosphere 数据集上 Precision 提升约 8%。
6. **TaxDistill 具备插件式设计**：可与任何序列比对算法集成，具有良好的扩展性。

### 优点

- **创新性**：首次将基因组基础模型作为教师网络引入知识蒸馏框架，应用于宏基因组分类标签校正，有效解决噪声标签问题。
- **实用性**：采用即插即用设计，可直接与现有序列比对工具（MMseqs2、Metabuli、Kraken2）兼容，无需重新训练基础分类器，便于实际部署。
- **鲁棒性**：通过软标签知识蒸馏，实现自然正则化，防止轻量学生网络过拟合噪声；同时通过置信度阈值实现严格假阳性控制，适合临床和生态监测等高可靠性需求场景。
- **实验充分**：跨 7 个多样数据集、3 种初始工具、多个基线对比，消融实验和可视化分析（桑基图）全面验证了方法有效性。
- **不确定性感知**：模型能自动识别边界模糊的样本，保守地标记为未知，优于 Taxometer 的硬标签策略。

### 不足与局限

- **受限于教师模型表示能力**：当前框架仅微调分类头，当处理高度复杂样本时，教师模型的固有偏差可能传播到学生网络，文中指出需要探索更先进的蒸馏架构。
- **缺乏新物种发现能力**：严格假阳性控制本质上是基于置信度的拒绝机制，不能进行新物种的 de novo 发现，无法识别参考数据库中完全未知的微生物。
- **计算成本增加**：纳入基因组基础模型（500M 参数）增加了推理时间，尽管在可接受范围（相比 Taxometer 增加约 1~2 小时），但对于超大规模宏基因组数据集可能仍有压力。
- **实验覆盖局限性**：虽然使用了 7 个 CAMI2 数据集，但均为模拟或 benchmark 数据，真实野外环境迁移效果待验证；文中未讨论对不同测序平台、读长、覆盖度等变化的鲁棒性。
- **超参数依赖**：蒸馏权重 α 和温度 T 需在特定数据集上调优（表 1 展示 Marine 数据集最佳为 α=0.3, T=4），泛化性需进一步验证。
- **仅评估物种级**：未涉及属、科等更高层级分类性能；也未探讨对不同分类等级（如物种、株系）的校正表现差异。
