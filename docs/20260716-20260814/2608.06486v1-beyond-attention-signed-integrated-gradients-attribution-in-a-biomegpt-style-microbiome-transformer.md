## 摘要
在特征token化的Transformer（arXiv:2106.11959）中，例如BiomeGPT（doi:10.64898/2026.01.05.697599），每个输入token通过融合固定身份与样本特定测量值构建：固定物种与可变丰度，T = S + A。为了解释此类模型中的下游分类，先前的工作检查特殊[CLS] token的注意力权重（arXiv:2106.11959, arXiv:1810.04805, BiomeGPT），以按重要性对样本token进行排序。这些权重有两个关键限制：它们是非负的，因此无法区分疾病支持证据与健康支持证据（arXiv:2201.12114）；并且它们在token融合之后起作用，掩盖了输入来源S和A各自如何影响输出。为解决此问题，我们使用积分梯度（arXiv:1703.01365），一种有符号的、融合感知的归因方法，并为像BiomeGPT这样的特征token化模型提出了一个源自基线的基准T' = S + A_0，该基线保留物种身份作为固定生物学坐标，同时隔离丰度变化的影响。应用于疾病与健康决策边界，它产生的极性明确区分致病微生物信号与保护性微生物信号。我们表明，这种基于梯度的方法揭示了物种-丰度方向关系以及完全被无符号[CLS]注意力权重掩盖的敏感性诊断。我们进一步推荐二阶积分Hessian（arXiv:2002.04138）以揭示微生物群落相互作用规则：一个成员的扰动如何改变模型对另一个成员的敏感性，以及哪些其他物种在给定丰度水平下将模糊案例推向疾病或健康。这为BiomeGPT提供了一种有原则的可解释性方法，并推广到其他平滑且可微分的特征token化Transformer。代码可在https://github.com/nohren/token-source-attribution获取。

## Abstract
In a feature-tokenized transformer (arXiv:2106.11959) such as BiomeGPT (doi:10.64898/2026.01.05.697599), each input token is built by fusing a fixed identity with a sample-specific measurement: a fixed species and a variable abundance, T = S + A. To interpret downstream classification in such models, prior work inspects the attention weights of the special [CLS] token (arXiv:2106.11959, arXiv:1810.04805, BiomeGPT) to rank sample tokens by importance. These weights have two critical limitations: they are nonnegative, so they cannot separate disease-supporting from health-supporting evidence (arXiv:2201.12114), and they act after token fusion, obscuring how the input sources S and A each affect the output.   To address this we use Integrated Gradients (arXiv:1703.01365), a signed, fusion-aware attribution method, and propose a source-derived baseline T' = S + A_0 for feature-tokenized models such as BiomeGPT, which preserves species identity as a fixed biological coordinate while isolating the effect of abundance variation. Applied to a disease-versus-health decision margin, it yields polarity that explicitly separates pathogenic from protective microbial signals. We show that this gradient-based approach uncovers species-abundance directional relationships and sensitivity diagnostics entirely obscured by unsigned [CLS] attention weights. We further recommend second-order Integrated Hessians (arXiv:2002.04138) to expose microbiome community interaction rules: how a perturbation in one member alters the model's sensitivity to another, and which other species drive ambiguous cases toward disease or health at a given abundance level. This provides a principled approach to explainability in BiomeGPT that generalizes to other smooth and differentiable feature-tokenized transformers. Code is available at https://github.com/nohren/token-source-attribution

**研究动机：**
- 在特征token化的Transformer架构中（如BiomeGPT），每个输入token由**固定物种身份（S）**与**样本特定丰度（A）**相加融合而成（T = S + A），是微生物组数据分析中的一种典型设计。
- 已有解释工作通常直接检查[CLS] token的注意力权重，用以对样本token进行重要性排序。
- 但作者指出，**[CLS]注意力权重存在两个关键缺陷**：
  1. 注意力权重非负且归一化（α ∈ [0,1]），**无法区分“支持IBD分类”与“支持健康分类”的证据极性**，高注意力不代表正贡献；
  2. 注意力作用于**融合后的token**，无法揭示物种身份S与丰度A各自对模型输出的独立影响。

**核心问题：**
> 如何在特征token化微生物组Transformer中，获得**带符号（极性）的、融合感知的、可解释的**样本特征归因，以替代无符号的[CLS]注意力排名？

**整体含义：**
- 本文主张以**积分梯度（Integrated Gradients, IG）**对“IBD−健康”logit差值进行归因，用正负号表达物种丰度是推动疾病还是支持健康的证据方向。
- 同时提出一种**源派生基线（source-derived baseline）**：T' = S + A₀（A₀为零丰度嵌入），使归因过程保留物种身份作为固定生物坐标，而只对丰度变化进行归因。
- 该解释框架原则上可泛化到其他平滑可微的特征tokenized Transformer架构。

## 二、方法论：核心思想、关键技术细节与公式

### 2.1 核心思想
1. **将解释目标定义为“IBD−健康”决策边界**：  
   F(S, A) = z_IBD(S, A) − z_Healthy(S, A)
   - 正归因 → 增加IBD边际；
   - 负归因 → 支持健康分类。
2. **使用积分梯度（IG）**：沿基线到输入的路径对梯度做积分，满足**完备性**（attributions之和 = 输出变化量），天然带有正负极性。
3. **保留物种身份、只归因丰度**：基线的构造应保证加性融合下物种身份S在整个路径中固定不变，仅丰度A从零丰度嵌入A₀移动到观测值。

### 2.2 关键技术细节

**融合结构：**  
T = S + A，其中S = Embed_ID(sᵢ)，A = MLP_AB(aᵢ)

**源派生基线：**  
T′ = S + A₀, A₀ = MLP_AB(0)

**路径定义：**  
A_α = A₀ + α(A − A₀)，S_α = S（固定）

**源级IG公式：**  
- IG_S = (S − S′) ⊙ ∫₀¹ ∂F/∂S dα = 0（因为S′ = S，位移为零）
- IG_A = (A − A′) ⊙ ∫₀¹ ∂F/∂A dα

**等价性论证：**  
在加性融合（∂T/∂S = ∂T/∂A = I）下，源梯度相等，即G_S = G_A；因此融合token级IG与丰度源级IG等价：IG_T = IG_A。这表明物种身份虽不产生直接归因，但始终作为上下文参与梯度计算，**“物种归因为零”是设计选择而非信息损失**。

**二阶扩展建议：**  
推荐Integrated Hessians以刻画**物种间丰度-丰度交互作用**：  
Γ_{Aᵢ,Aⱼ} = ΔAᵢᵀ [∫∫ αβ ∂²F/(∂Aᵢ∂Aⱼ) dαdβ] ΔAⱼ  
用于解释某一物种丰度如何调节模型对其他物种的敏感性。

## 六、主要结论与发现

1. **[CLS]注意力权重不足以解释BiomeGPT类模型**：
   - 非负权重大不等同于正向贡献；
   - 一个获得巨大注意力值的token可能实际在推动模型远离IBD判断（如Staphylococcus epidermidis与Collinsella massiliensis在注意力排名中很高，但IG显示它们是强的健康支持者）。
2. **IG在logit差值上的符号归因有效**：
   - 正归因增加IBD边际，负归因降低边际；
   - 真阳样本平均归因为正，真阴样本平均归因为负，与目标定义一致。
3. **源派生基线T' = S + A₀语义合理且数值稳定**：
   - 路径上物种身份固定，只移动丰度，保持生物学上下文；
   - Captum收敛误差比全零基线更小。
4. **IG揭示注意力完全掩盖的现象**：
   - 物种与丰度之间的**方向性关系**；
   - 丰度-归因响应曲线显示非线性和非单调响应模式，同一种群在不同丰度区间可能改变证据方向；
   - 路径平均梯度GA可识别“低丰度但高敏感”的物种。
5. **二阶Integrated Hessians有潜力**，可揭示物种间相互作用规则，但留作未来工作。

1. **实验覆盖范围有限**：
