## Abstract
Summary: This paper presents MBRarefy, an R package that provides a reproducible workflow for alpha diversity analysis under confounding from heterogeneous library sizes. Building on the multi-bin rarefying approach in Li et al (2024), MBRarefy supports alpha diversity association analysis with repeated rarefying, bin-wise testing, and cross-bin meta-analysis. A key new feature is automated, data-adaptive selection of library size bin thresholds via a genetic algorithm (GA), which replaces ad hoc cutpoints with an objective optimization procedure based on the rarefying-derived profiles. The package also supports routine data-management tasks, including file-based sample-wise processing and standardized output generation, enabling users to execute the full analysis pipeline from raw count files to combined inferential results.   Availability and implementation: The R package MBRarefy is freely available on GitHub at https://github.com/mli171/MBRarefy.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：在微生物组、免疫组库等高通量测序研究中，α多样性（如物种丰富度、Shannon指数）经常用于关联分析，但样本间的文库大小（总测序深度）异质性会引入混杂偏倚：即使生物学多样性不变，文库更大的样本倾向于表现更高的α多样性。传统做法是将所有样本稀疏化到同一深度，但会导致低深度样本被丢弃，同时稀疏化后的多样性仍可能与原始文库大小相关（即残差依赖），影响分析结果的可重复性。
- **研究动机**：已有的多箱稀疏化方法（Li et al., 2024）通过按文库大小分层并在各层内进行稀疏化，再跨层进行元分析，能够保留更多样本和信息。但该方法缺少自动、数据自适应的分箱阈值选择方式，以往依赖人为设定的截点（ad hoc cutpoints），主观性强且缺乏客观标准。
- **整体含义**：本文提出MBRarefy R包，首次引入遗传算法（GA）自动优化分箱阈值，使得分箱过程客观、可重复，并集成重复稀疏化、逐箱检验、跨箱元分析及残差诊断，形成从原始计数文件到推断结果的完整工作流，提高了α多样性关联分析的可靠性和可重复性。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：将分箱阈值选择视为有序节点放置（ordered knot placement）问题，基于网格化的稀疏化后α多样性轮廓，利用遗传算法最小化分箱内α多样性与原始文库大小之间的加权残差关联（通过部分R²度量），从而得到数据自适应的最优分箱方案。
- **关键技术细节与流程**：
  1. **预处理**：输入每个样本的计数文件；计算每个样本的文库大小 \( L_i \)。
  2. **网格化稀疏化轮廓**：用户指定一组稀疏化深度网格 \(\{m_1 < m_2 < \cdots < m_M\}\)，对每个样本在每个允许深度（\(L_i \ge m_j\)）进行重复稀疏化（可自定义重复次数 nRep），计算每个深度的α多样性均值，得到样本×深度矩阵 \(\alpha_i(m_j)\)。
  3. **GA最优截点选择**：
     - 目标：选择有序内部网格索引 \(\tau_1 < \tau_2 < \cdots < \tau_K\)（将文库大小范围划分为K+1个箱）。
     - 每个样本 \(i\) 被分配到箱 \(b\)（若 \(m_{\tau_{b-1}} \le L_i < m_{\tau_b}\)），取该箱下界深度处的多样性值 \(\tilde{\alpha}_{ib} = \alpha_i(m_{\tau_{b-1}})\)。
     - 每个箱内拟合回归模型 \(\tilde{\alpha}_{ib} = \beta_{0b} + \beta_{1b} g(L_i) + Z_i^\top \gamma_b + \varepsilon_{ib}\)（默认 \(g(L_i)=\log_{10}L_i\)），计算部分R² \(R^2_{b,L|Z}\)。
     - 遗传算法最小化加权平均的箱内部分R²：\(Q(\tau) = \frac{\sum_{b=1}^{K+1} w_b R^2_{b,L|Z}}{\sum w_b}\)，其中权重 \(w_b\) 可选等权或样本数加权。
     - 支持固定箱数（fixed-K）和可变箱数（varying-K）模式，后者由GA自动推断最优箱数。
     - 使用GAReg包（Li et al., 2026）中的GA实现，染色体编码为截点索引+哨兵值，违反最少样本数或间距约束的方案被惩罚。
  4. **多箱关联分析**：根据选定的截点分配样本到箱，提取对应下界深度的α多样性值，进行逐箱关联检验（可加入协变量），然后通过元分析（等权、样本量权重或逆方差权重）合并各箱效应，最后提供残差诊断（检验箱内α多样性与原始文库大小是否仍有显著关联）。
