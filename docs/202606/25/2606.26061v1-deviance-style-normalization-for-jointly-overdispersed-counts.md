## 摘要
我们引入了一种Dirichlet-多项（DM）偏差残差化方法，用于处理稀疏且联合过度离散的计数矩阵，这是基于测序的生物化学分析中常见的情景。DM零模型将每个样本的计数向量视为一个固定总数的组成，由一个标量浓度α₀控制过度离散，并通过将独立的负二项特征计数条件化于观测到的样本总数而精确得到——这使得DM成为标准逐特征过度离散计数模型的联合条件模拟。所得变换保留了精确稀疏性，每个非零条目在常数时间内评估，在单个计数上与多项残差一致，根据零模型容忍的过度离散来收缩重复计数残差，并在α₀→∞时恢复为多项残差。相同的固定离散比较原则通过广义DM和Dirichlet-树多项扩展到有序和树状结构特征，生成一个单一的残差族，在共同的组合逻辑下包含联合和逐特征计数零模型，并且计算轻量，足以嵌入现有的稀疏处理流程。

## Abstract
We introduce a Dirichlet--multinomial (DM) deviance residualization for sparse, jointly overdispersed count matrices, the regime that dominates sequencing-based biochemical assays. The DM null treats each sample's count vector as a fixed-total composition with a single scalar concentration $α_0$ governing overdispersion, and arises exactly by conditioning independent negative-binomial feature counts on the observed sample total -- making the DM the joint conditional analogue of standard feature-wise overdispersed count models. The resulting transform preserves exact sparsity, evaluates in constant time per nonzero entry, agrees with multinomial residuals on singleton counts, shrinks repeated-count residuals according to the overdispersion the null tolerates, and recovers the multinomial residual as $α_0\to\infty$. The same fixed-dispersion comparison principle extends to ordered and tree-structured features via the generalized DM and the Dirichlet-tree multinomial, giving a single residual family that subsumes joint and feature-wise count nulls under a common compositional logic and is computationally lightweight enough to drop into existing sparse pipelines.

- **结构化扩展有效**：DTM在微生物组和空间转录组数据上展示了优势，能更好地利用已知的树状结构，产生更一致的几何表示。
- **计算优势**：线性于非零元数量（O(nnz)）的计算复杂度和严格的稀疏性保持，使其在大规模应用中具有实际优势。

### 7. 优点：方法或实验设计上有哪些亮点

- **理论扎实**：从统计理论（指数族、离差、条件分布）出发，推导出简洁优雅的形式。每个关键性质（如与singleton一致、对重复计数收缩）都有严格的命题证明。
- **计算轻量**：是真正的“即插即用”轻量级方法，可以无缝嵌入大多基于稀疏矩阵的现有流程（如scranpy, Seurat），无需巨大的算力投入。
- **实验全面且深度**：实验设计非常出色，不仅测试了方法在标准任务上的表现，还深入探讨了其理论特性（如校准性、鲁棒性、参数恢复）。对**方法局限性**的坦白分析（如对分类任务可能略逊于多项分布）反映了研究的客观性。
- **统一框架**：成功地将多项、DM、GDM和DTM统一在一个比较残差的框架下，使不同模型之间的关系变得清晰。
- **推动交叉领域**：方法不局限于生物信息学，还成功应用到NLP（文本）和推荐系统（用户-物品交互），证明了其方法的广泛应用潜力。

### 8. 不足与局限

- **单一全局浓度假设**：DM的核心假设是使用一个**全局的**标量浓度 \(\alpha_0\)。当不同特征的过度离散程度差异巨大，且这种差异不是由已知层次结构（DTM可以处理）引起时，这个假设可能过于简化。这可能导致在高度异质性的数据中性能不如更灵活（但更贵）的模型（如logistic-normal模型）。
- **对树和顺序的依赖**：DTM和GDM扩展虽然强大，但**严重依赖预定义的树或顺序**。如果给定的树是错误的或顺序是无意义的，其性能可能反而不如平坦的DM。论文也通过实验（如B.6节）验证了这一点。
- **与深度学习方法的比较**：尽管在部分任务（如scATAC-seq）上DM表现优异，但在更复杂的单细胞图谱整合上（图4），**深度学习方法（scVI）仍展现出更强的embedding质量**。作者对此坦承，但也指出深度方法在差异表达分析中的FDR控制上存在问题，DM是更“保险”的选择。这表明DM不能完全替代深度方法，而是提供了不同的权衡。
- **未提及多批次/协变量整合**：论文中的零模型是单一的全局组成 \(\pi\)。虽然作者在“讨论”中提到了可以扩展为条件性组成（如考虑批次），但正文实验未系统性地评估DM在多批次数据整合中的表现。
- **资源与算力信息缺失**：如前所述，论文未提供详细的GPU和训练时长信息，这在一定程度上降低了结果的可复现性，尤其是在与深度学习方法的对比中。
